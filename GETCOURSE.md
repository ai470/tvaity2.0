# Передача меток в GetCourse

Все три страницы (`/reg-short/`, `/reg/`, `/reg-01/`) используют реализацию
`short-land/gc-tracking.js`. Она читает текущий URL, переносит все `utm_*` и `ref`
в URL iframe, приводит имена к lowercase и сохраняет служебный `id` виджета.
В `loc` передаётся полный адрес страницы. Значения меток не меняются.
Пробелы кодируются как `%20` для совместимости с существующей формой.

Проверены виджеты `1657350`, `1657351`, `1657552`, `1657553`, включая значения
реальных полей формы; формы при проверке не отправлялись.

## Дополнительная правка в редакторе самого GetCourse

В настройках этих форм есть пользовательская функция `getGet(name)`, которая
использует регулярное выражение и `decodeURI`. Она неправильно декодирует
зарезервированные символы (`&`, `+`, `=`, `#` и другие) и пустые значения.
Это отдельный код на домене GetCourse. Сайт передаёт корректный URL, но не может
изменять JavaScript внутри iframe другого домена.

Чтобы значения с такими символами попадали и в дополнительные поля без искажений,
замените **только функцию `getGet`** в пользовательском JavaScript каждого виджета
на следующую. Существующие строки заполнения полей через `.val(getGet(...))`
оставьте как есть:

```js
function getGet(name) {
  var value = new URLSearchParams(window.location.search).get(name.toLowerCase());
  return value === null ? "(not set)" : value;
}
```

Эта правка в админке GetCourse в рамках деплоя не выполнялась: доступа к редактору
виджетов в окружении нет. Обычные метки, `ref`, пробелы и передача всех параметров
в iframe проверены. Не применять дополнительный `decodeURI`/`decodeURIComponent`
после `URLSearchParams.get`: значение уже декодировано.

## Проверки

```bash
node --test tests/gc-tracking.test.cjs
python3 -m unittest discover -s deploy -p 'test_*.py' -v
```

`tests/browser-smoke.cjs` требует установленного Playwright. Он проверяет девять
размеров экрана в Chromium (два в WebKit), открытие/закрытие формы, отсутствие
обрезания, URL iframe и реальные поля GetCourse. По умолчанию проверяется прод;
для локальной проверки можно задать `SHORT_BASE`, `LEGACY_OVERLAY` и `SCREENSHOTS`.
